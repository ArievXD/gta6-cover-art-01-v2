Vice Panels — a GTA 6-style multi-panel cover maker. Turn a photo and a caption into GTA 6-style cover art: three layouts (Hero + two, Four up, Wide strip), four colour grades (Sunset, Neon, Noir, Original), per-panel crop and zoom, caption styles, a tagline, and PNG export in 1080x1080, 1080x1350, and 1920x1080. Fully offline static web app — no build step, no Rockstar artwork, all art drawn in code. Open `app/index.html` in Chrome, or serve it locally.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
